## E-COMMERCE-SALES-ANALYSIS

## PROJECT OVERVIEW

   This project analyzes e-commerce sales data using Python, NumPy, Pandas, Matplotlib.

   the main objective is to clean, process, analyze, and visualize sales data to identify important business insight such as revenue, top product, category, performance, 
   city-wise sales, and monthly revenue trends.

## PROJECT OBJECTIVES

  > Analyze e-commerce sales data
  > perform data cleaning
  > calculate Revenue and Profit
  > Identify top-performing products
  > Analyze category-wise performance
  > Analyze city-wise sales
  > Analyze monthly revenue trends
  > Create meaningful data visualizations
  > Generate business insight for decision-making

## TECHNOLOGIES USED

  Python, NumPy, Pandas, Matplotlib, Excel/CSV, VS Code/Jupyter Notebook/Google Colab

## KEY FEATURES

1. Data loading
2. Data Cleaning
3. Revenue Analysis
4. Profit Analysis
5. Product Analysis
6. Category Analysis
7. City Analysis
8. Monthly Trend Analysis
9. Data Visualization
10.Business Storytelling
